TOS images
==========

The Atari ST's operating system, TOS, is in ROM on a real machine. On
BMAtariST it is a file in this folder.

EmuTOS (etos1024k.img) is already here: a free TOS, under the GNU GPL, that
runs on every machine BMAtariST emulates (ST, STE, Mega ST, Mega STE, TT
and Falcon) and runs most software. See https://emutos.sourceforge.io/.

Atari's own TOS is copyrighted and not included. If you have images of
your own machine's ROMs, copy them here: any file ending .img, .rom or
.tos that is 192K (TOS 1.00 to 1.04), 256K (TOS 1.06, 1.62, 2.06), 512K
(TOS 3.0x for the TT, 4.0x for the Falcon) or 1024K. Then choose one in
the menu (F12, Machine, TOS).

Which TOS for which machine:
  ST, Mega ST         TOS 1.00, 1.02, 1.04 (or 2.06)
  STE, Mega STE       TOS 1.06, 1.62 (STE), 2.05, 2.06
  TT                  TOS 3.05, 3.06
  Falcon              TOS 4.02, 4.04
  all of them         EmuTOS

A TOS that doesn't suit the machine doesn't start: Hatari's log (see the
User Guide) says why, and the menu can still be opened to choose another.
