Licences
========

BMMacintosh itself is under the GNU General Public License version 3
(LICENSE.txt in the root of the card). It includes code from other
projects; this folder has their notices and licences:

  basilisk2.txt   Basilisk II, the Mac II and Quadra emulator (GPL
                  version 2 or later).
  slirp.txt       slirp, the Mac II's network (its own licence, BSD,
                  MIT).
  umac.txt        umac, the Mac Plus emulator (MIT; its parts from
                  Basilisk II GPL version 2 or later).
  musashi.txt     Musashi, umac's 68000 (MIT), with the SoftFloat notice
                  for its floating point emulation.
  zlib.txt        The zlib compression library (zlib licence), for MAME's
                  zipped ROM sets.
  crt-pi.txt      The crt-pi CRT shader by davej (GPL version 2 or later).
  Mesa-MIT.txt    Material from the Mesa 3D graphics library's Broadcom
                  V3D drivers, for the Raspberry Pi 4 and Pi 5 GPU (MIT).
  Linux-V3D.txt   Parts of the Linux kernel's V3D and BCM2835 power
                  drivers, for the Raspberry Pi 4 and Pi 5 GPU (GPL
                  version 2 or later).
  Apache-2.0.txt  The Apache License 2.0, for the BMC64 code under it.
  GPL-2.0.txt     The GNU General Public License version 2, for the files
                  above under it, and the menu's font (the Linux console's
                  lat1-16, from the kbd package, GPL version 2 or later).
  newlib.txt      Aggregate newlib C/math library notices.
  libgloss.txt    Aggregate libgloss runtime-adaptation notices.
  GCC-Runtime.txt The GCC section of the Arm GNU Toolchain 15.2.rel1
                  licence, with the GCC Runtime Library Exception 3.1,
                  for the GCC runtime code the kernels link.

The Raspberry Pi firmware and Wi-Fi firmware licences are with the
firmware (LICENCE.broadcom, COPYING.linux, and the firmware folder).
